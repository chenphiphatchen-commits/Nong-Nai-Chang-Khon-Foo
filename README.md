## 🎯 Project Overview
This project presents an innovative approach to solving **"Data Lag"** in construction site reporting. By replacing manual reporting and traditional coding (e.g., Google Apps Script) with a **Low-Code/No-Code architecture via n8n**, we have created a highly scalable and intelligent system. 

Foremen can effortlessly update their daily progress via Line OA, while the integrated **Google Gemini AI** extracts natural language data, performs automated Critical Path Method (CPM) gap analysis, and updates the central database in real-time.

---

## 🛠️ Why n8n instead of Google Apps Script (.gs)?
While traditional implementations rely on `.gs` scripts for basic Line Bot responses, our architecture leverages **n8n** to achieve:
1. **LLM Integration:** Seamlessly connecting to Large Language Models for complex Natural Language Processing (NLP).
2. **Predictive Analysis:** Automatically detecting delays and proposing strategic countermeasures (e.g., Overtime allocation) before they impact the CPM baseline.
3. **Agility:** Rapid workflow orchestration without hard-coding complex logic.
